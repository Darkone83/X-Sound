# X-Sound Branding Requirements  
**Darkone Customs / Darkone83**

This document defines the branding rules for all derivatives, forks, and
redistribution of the X-Sound hardware and software.

---

## 1. Branding Must Remain Intact
All Darkone Customs and Darkone83 branding MUST remain untouched in:

- PCB silkscreens  
- Schematics  
- 3D models  
- Firmware UI elements  
- Documentation  
- Images/renderings  
- Marketing material derived from the project  

Branding includes (but is not limited to):

- "Darkone83"
- "Darkone Customs"
- "Team Resurgent"
- Logos, icons, and symbol marks used in PCB art

Removal, modification, shrinking, obscuring, or overwriting of these elements
is **not permitted**.

---

## 2. Required Attribution
Any forks, derivatives, or commercial uses **must clearly state**:

**"Original Design by Darkone83 / Darkone Customs"**

This must appear in:

- README files  
- Product listings (if sold)  
- Printed or digital documentation  
- Any derivative hardware silkscreens  

---

## 3. Additional Branding (Allowed)
You may add:

- Your own maker mark  
- Your logo  
- Version codes  
- Batch identifiers  
- Assembly information  

…as long as the original branding remains **visible and unaltered**.

---

## 4. Use of Name and Logos
You *may not* imply that Darkone Customs endorses or supports derivative works.

You *may not* use the logos or branding for unrelated projects unless granted
permission.

---

## 5. Approved Files
Official versions of logos, silkscreen assets, and identifiers will be included
under:

```
/branding/
```

You must use the provided official versions if they exist.

---

## 6. Reporting Violations
If you find a fork, derivative, or commercial listing violating these rules,
open an Issue on the repository with links and details.

---

This branding policy protects the identity and authorship of the X-Sound project
and all associated Darkone Customs work.
